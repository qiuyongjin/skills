# skills

A collection of reusable AI skills.

## Skills

| Skill | Description |
| --- | --- |
| [humanizer](./skills/humanizer) | Remove signs of AI-generated writing from text. Use when editing or reviewing copy to make it read more naturally. |
| [summarize](./skills/summarize) | Summarize URLs or files (web, PDFs, images, audio, YouTube) with the [`summarize`](https://summarize.sh) CLI. |
| [eli5](./skills/eli5) | Explain a topic like I'm 5 years old, using an HTML artifact with big pictures and few words. |
