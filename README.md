# skills

A collection of reusable AI skills.

## Skills

| Skill | Description |
| --- | --- |
| [humanizer](./humanizer-1.0.0) | Remove signs of AI-generated writing from text. Use when editing or reviewing copy to make it read more naturally. |
| [summarize](./summarize-1.0.0) | Summarize URLs or files (web, PDFs, images, audio, YouTube) with the [`summarize`](https://summarize.sh) CLI. |
